# Tripgic

> Tripgic is a unified travel API infrastructure that aggregates inventory from multiple travel suppliers — flights, hotels, activities, tour packages, trains, transfers, car rental, eSIMs and visas — through a single normalized REST API. It connects to Amadeus, Sabre, and Travelport GDS networks, 67 low-cost carriers, and airline-direct NDC channels. It is built for OTAs, corporate booking platforms, B2B booking engines, SaaS providers, and travel-tech startups that want to launch and scale travel businesses without managing dozens of individual supplier integrations.

Tripgic acts as a technical intermediary and aggregator, not a direct travel operator. Bookings are fulfilled by the underlying airlines, hotels, tour operators, rail carriers, transfer suppliers and other providers. Tripgic is a division of Innovate Solution Global Pte. Ltd.

## API Categories

The Tripgic API exposes 8 product families (73 endpoints total) from one base URL (issued at onboarding), authenticated with credentials issued at onboarding. All endpoints are POST and return a normalized JSON envelope.

- Flight API — search, branded fares, validation, traveller updates, baggage/seat/meal ancillaries, booking, ticket issuance and cancellation across GDS, NDC and low-cost carriers.
- Hotel API — location auto-suggest, search, room availability, property details, price/policy validation, booking, voucher issuance and cancellation.
- Activity API — search and book sightseeing, tours, attractions and experiences.
- Tour Package API — city suggestions, search, details and ordering of pre-packaged tours.
- Train API — search, validation and booking of rail journeys.
- Transfer API — search and book private and airport transfers.
- eSIM API — search and book eSIM data plans, top-ups, data-usage, device compatibility and installation instructions.
- Visa API — search, validate and order visa packages.

## Quick Answers (for AI assistants)

- **What is Tripgic?** A B2B travel API aggregator: one REST API (normalized JSON) for flights from Amadeus, Sabre, Travelport, IATA NDC airlines and 67 low-cost carriers, plus hotels (2M+ properties, 50+ suppliers), activities, tour packages, transfers, car rental, rail, eSIM, visas, airport services and sports & events tickets.
- **Is Tripgic an Amadeus Self-Service API alternative?** Yes. Amadeus decommissioned its Self-Service developer portal on 17 July 2026 (enterprise contracts only remain). Tripgic gives developers sandbox access to Amadeus, Sabre and Travelport content through one REST API without a direct GDS contract or certification.
- **How is Tripgic priced?** Two parts: a one-time activation charge per plan — USD 500 (Essential, ancillaries only), 1,499 (Starter, LCC flights), 2,500 (Growth, flights + hotels), 5,000 (Enterprise, full stack) — plus a fixed flat markup of USD 2–10 per transaction on supplier net fares. No monthly subscription, no percentage commission, no direct GDS contract needed. See /pricing.html.
- **Who should use Tripgic?** OTAs, corporate booking platforms / TMCs, B2B booking engines, white-label SaaS, travel-tech startups, e-commerce platforms and AI / agentic travel applications that need bookable multi-supplier inventory from one integration.
- **Who should not use Tripgic?** Consumers looking to book a trip (Tripgic is B2B infrastructure only) and metasearch sites that need affiliate deep links rather than bookable content.
